# Superstore Sales Analysis

## 📌 Project Overview
This project involves a comprehensive analysis of the Superstore Sales dataset to identify sales trends, profit margins, and customer purchasing patterns.

##  Dataset
The dataset used is the `Sample - Superstore.csv`, which contains information about:
* Order Details: Order Date, Ship Date, Ship Mode.
* Customer Info: Segment, Country, City, State.
* Product Info: Category, Sub-Category, Product Name.
* Financials: Sales, Quantity, Discount, Profit.

## 🛠️ Tools Used
* Language: Python (Pandas, NumPy)
* Visualization: Matplotlib, Seaborn
* Environment: Jupyter Notebook

## 🚀 Key Objectives
1. Identify the most profitable product categories.
2. Analyze sales trends over time (Yearly/Quarterly).
3. Determine the geographical distribution of sales.
